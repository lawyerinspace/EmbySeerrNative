Discover

Open Seerr ↗

Adds two native channels — Discover Movies and Discover Shows — to every Emby app. They show lists from Seerr and TMDB, hide what you already have, mark requested titles, play trailers, and (optionally) let people request a title by adding it to their Favourites. Requests always go through Seerr as the person's own Seerr account.

TMDB

Needed for TMDB lists, the list builder (genres, streaming services, age ratings), show age-rating filters and season trailers. Free: themoviedb.org → Settings → API. Either the short API Key or the long API Read Access Token works. Only sent to api.themoviedb.org.
Checks only the key above. To check a list, use Preview on the Channels & Lists tab.

Who can request

Requests are sent to Seerr as the person who made them, so their Seerr permissions, request limits and auto-approval apply, and the request appears under their name in Seerr. Each Emby user is matched automatically to the Seerr account that belongs to their Emby login — created when they sign in to Seerr with Emby, or by Seerr → Settings → Users → Import Emby Users. People without a Seerr account can still browse and watch trailers, but cannot request.

Lists every Emby user and the Seerr account their requests use (uses the saved Seerr settings).

Channels

Emby identifies a channel by its name: after renaming, restart Emby, then set channel access (Users → Access) and home-screen rows again for the renamed channel.

Lists

Each list becomes a folder in its channel. Use ↑ ↓ to change the folder order, the tick box to hide a folder without deleting it, and Preview to see what a list returns today. Titles inside a folder are ordered by Emby (usually alphabetically), so a list's "pick titles by" setting decides which titles are included rather than their order on screen.

Where requested titles are stored

Two destinations — for example a streaming/cloud service and your own storage. For each, pick the Radarr and Sonarr root folder and tags that Seerr should send with the request. The folder and tag lists come from Seerr's Radarr and Sonarr servers; choose Seerr's default to leave that part to Seerr. Requests made from Emby use the default destination. Requests made in Seerr itself use Seerr's own settings.

Tags replace the default tags Seerr would otherwise add for that request. Seerr override rules (Seerr → Settings) can still change the folder or tags. After changing this, request one title and check where it lands in Radarr/Sonarr.

Playback

How it works

  • The channels refresh by themselves after you save and about 20 seconds after a request. To refresh by hand, use ⟳ Refresh channels at the top of this page (the same as Dashboard → Scheduled Tasks → Refresh Internet Channels, but with fresh data from Seerr and TMDB).
  • Each title's first line (✔ / ➕ / ⏳ and what ♥ does) is shown as the tagline, on its own line above the description.
  • Give people access to the channels in Users → (user) → Access, and add folders to their home screen in Settings → Home screen.
  • ♥ = request (when enabled on File Management). ▶ Play = trailer. Everything else (approvals, request history, issues) is in Seerr.
  • The Discover channels appear with a folder icon in the Emby web app's side menu. Emby chooses that icon for every channel, and a plugin cannot change it. The channel artwork shows on the home screen and under My Media.

Date placeholders

TMDB links can contain placeholders that are filled in from the Emby server's clock every time the list is read, so date windows move forward by themselves. The list builder adds them for you; you only need these for your own links.

{today}Today's date, e.g. 2026-10-27
{today-7d} {today+30d}Today minus / plus days (d), weeks (w), months (m) or years (y), e.g. {today-1m}
{start_of_week} {end_of_week}Monday and Sunday of this week
{start_of_month} {end_of_month}First and last day of this month (also with offsets, e.g. {start_of_month-1m} = first day of last month)
{start_of_year} {end_of_year}1 January and 31 December
{year} {year-1}The year as a number, for filters such as primary_release_year

"Today" is the Emby container's local time. Set TZ= to your time zone (e.g. TZ=Europe/London) in the container's environment so the day changes at your midnight.

Writing your own TMDB link

Choose Custom TMDB link in the list builder and paste any https://api.themoviedb.org/3/… link that returns titles (/discover/movie, /discover/tv, /trending/…, /movie/top_rated, /tv/popular …). api_key and page in the link are ignored. Useful filters:

sort_by=popularity.descAlso vote_average.desc, vote_count.desc, primary_release_date.desc (movies), first_air_date.desc (shows)
primary_release_date.gte / .lteMovie release window, e.g. ={today-1m}
first_air_date.gte / .lteShows that premiered in a window
air_date.gte / .lteShows with an episode airing in a window ("on air")
with_watch_providers=8|1899Streaming services (| = any of). Needs watch_region=US; add with_watch_monetization_types=flatrate for subscription only
with_genres=18|80 / without_genres=10762,10766Include any of / exclude genres (ids are listed in the builder)
without_keywords=210024Exclude anime
with_original_language=enOriginal language
vote_count.gte=200Skip titles with few votes
vote_average.gte=7Minimum TMDB score out of 10
certification_country=US
certification.gte=PG / .lte=PG-13		Age ratings from lowest to highest allowed, in that country's system (US movies: G, PG, PG-13, R, NC-17; US shows: TV-Y, TV-Y7, TV-G, TV-PG, TV-14, TV-MA). TMDB applies this to movies itself. For shows TMDB has no such filter, so Discover checks each show's rating; add include_unrated=true to keep shows with no rating in that country.

Troubleshooting

A channel or folder is emptyRun Test Seerr connection / Test TMDB connection (Connection tab) and Preview on the list. Then Dashboard → Logs → embyserver.txt, search for Discover.
A title is hidden as "already owned" but you don't have itPreview the list and hover over the owned poster: it names the Emby library item that matched (often a file identified as the wrong film — fix it with Identify in Emby) or says Seerr marks it as available (check the title in Seerr).
A show list with an age-rating filter is short or emptyMany shows have no rating in some countries. Choose a different country, or tick Keep shows without a rating.
A TMDB list is emptyUse Preview on the list: it shows TMDB's error (bad key, private list, unknown filter). Owned titles are hidden.
♥ does nothingFavourite-to-request must be on (File Management) and the person must have a Seerr link (Users → Check user links).
Request went to the wrong folderCheck File Management and any Seerr override rules.
No badgesBadges appear after the channel refreshes; look for could not draw poster badge in the log.
